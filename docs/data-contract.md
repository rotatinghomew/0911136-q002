# 领域资料与供数约定

## 数据含义

daily 是有效观测窗口的日累积值，observed_hours 为 0 至 24；0 小时的 rain_mm 必须为 null。day 为统一 UTC 自然日，仅有一条 station_id 与 day。eras 为仪器及位置稳定的一段时期，结束日不含。不同站同一 process_id 表示共同暴雨过程。thresholds 为讨论时使用的日累积阈值，不是尾部拟合的指定参数。只有完整日用于现有经验最大值摘要，部分日不代表完整日零雨。

## 现行摘要

`stormcast/analysis.py` 生成现行资料摘要（按观测年代的完整日经验分代统计）。源码和运行结果中的 scope 说明其统计边界，不能把未提供的推断当成已有能力。`stormcast/frequency.py` 的频率分析在 `legacy_empirical_summary` 中原样内嵌该摘要，不改变其结构与语义。

## 极端降雨频率分析

`stormcast/frequency.py` 与 `stormcast/extreme.py` 在现行摘要之上提供面向储备讨论的频率分析，业务运行仍只用标准库。

- **资料口径**：只有完整观测日（`observed_hours == 24` 且 `rain_mm` 非空）进入频率估计；部分日不补零、不外推。部分日已知雨量本身达到业务阈值时，仅作为"真实超越次数可能更高"的提示，不计入频次。有效观测年数由完整日数除以 365.25 得到，缺测年份与短观测乡镇因此不会被等长比较。
- **尾部分布**：采用广义帕累托分布（GPD）的超阈（POT）模型。参数给两套估计——L-矩（闭式、稳定，驱动自助区间）与极大似然（点估计方法学对照）；两者均在已知参数的合成 GPD 样本上做过恢复性验证。
- **阈值处理**：`thresholds` 表的业务阈值只用于讨论超阈频次，不作为尾部拟合参数。尾部拟合阈值取 0.90/0.95/0.975 经验分位并与业务阈值一起做敏感性诊断，比较各阈值下尾部形状是否稳定。
- **年代合并**：同一乡镇不同仪器年代在平稳性（同分布）假设下合并以凑足样本，同时输出各年代的分代超阈速率；速率差异大时明确提示合并假设可疑，应分年代解读。
- **重现期与超越概率**：重现期是年超越概率的倒数，表示长期平均间隔，**不代表每隔固定年数准时发生**。POT 模型下年超越概率为 `1-exp(-λζ)`，不是朴素的 `1/T`。每个重现期水平附 90% 自助区间（重采样超阈样本，超阈次数按泊松过程重抽样）。该区间刻画模型附近的抽样离散度，**不是经覆盖率校准的置信带**：在超阈样本仅百例量级时 GPD 形状参数存在小样本偏差，区间可能偏窄、对高重现期真值覆盖不足，应作为不确定性量级参考并与经验分位、阈值敏感性联合解读。
- **外推边界**：超过有效年数两倍的重现期标注为分布外推；超过五倍的重现期（如 19 年记录下的百年值）判为 `unsupported`，返回空值与说明而不是硬填。负形状（有界尾部）给出估计支撑上端点。超阈样本少于 40 个时不做分布拟合，只给经验分位。
- **联合超越风险**：相邻乡镇同日共同超阈直接由经验频次计算（联合日概率、年化联合发生率、条件概率、与独立假设的对照倍数），不拟合 copula 或多元分布；共同超阈次数过少时标注联合估计的抽样边界。共同观测窗口之外的联动无法估计。

## 供数接口

`GET /manifest` 返回 generation、tables（每表 count 与 sha256）及 metadata。`GET /tables/<name>?generation=<generation>` 返回同代 rows。供数换代时旧 generation 返回 HTTP 409，不允许将新代记录接入旧分析；不存在的表返回 404。表内容为稳定键唯一的完整同代记录，不是增量事件流。客户端对清单摘要进行核验。摘要使用 UTF-8、排序对象键、紧凑 JSON 的 SHA256，数组顺序保留供数端顺序。

字段与主键声明位于 `stormcast/schema.json`，合成资料位于 `fixtures/dataset.json`。`metadata.cutoff` 是供数展示截点，不自动为分析选择训练截止点。服务可将整个 dataset 原子替换为新一代，但不在同一 generation 下更改内容。

## 结果保存

`reports.py` 保存现有摘要及来源表摘要，report_id 是内容摘要，不是随机编号。相同内容生成相同编号，临时文件写入完成后原子替换目标文件；历史内容是否保留由调用者选择不同目标路径。服务只监听本机，不接入生产系统。
